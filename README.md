# FinanFlow — Frontend

Interface de login responsiva construída com React, TypeScript, Vite, Tailwind CSS v4 e Lucide React.

## Requisitos
- Node.js 20 ou superior
- npm

## Executar
```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite no terminal.

## Build de produção
```bash
npm run build
npm run preview
```

## Observação
Este projeto contém somente o frontend. O formulário possui validação básica de campos e estados demonstrativos, mas ainda não está conectado a uma API de autenticação ou ao login do Google.
